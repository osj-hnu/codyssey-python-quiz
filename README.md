# Python 콘솔 퀴즈 게임

## 1. 프로젝트 개요
Python 기본 문법과 객체지향 프로그래밍을 활용하여 터미널에서 실행하는 퀴즈 게임을 개발합니다. Git과 GitHub를 사용하여 기능별 변경 이력을 기록하고 협업합니다.

## 2. 퀴즈 주제 및 선정 이유
- **퀴즈 주제:** Python 기초 문법
- **선정 이유:** 입학연수에서 학습한 변수, 조건문, 반복문, 함수, 클래스 등 Python 기초 개념을 복습하기 위해 선정했습니다.
- **문항 수:** 5문항 이상 (각 문항은 문제, 선택지 4개, 정답 포함)

> 퀴즈 주제와 선정 이유는 실습 예시입니다. 실제 팀 프로젝트에서는 자유롭게 수정할 수 있습니다.

## 3. 주요 기능
1. **퀴즈 풀기:** 저장된 문제를 출제하고 정답 여부 및 최종 점수를 표시합니다.
2. **퀴즈 추가:** 문제, 선택지 4개, 정답 번호를 입력하여 새 퀴즈를 등록합니다.
3. **퀴즈 목록:** 등록된 퀴즈 목록을 확인합니다.
4. **점수 확인:** 최고 점수를 조회하고 퀴즈 결과에 따라 갱신합니다.
5. **데이터 저장/불러오기:** 프로그램 종료 후에도 퀴즈와 최고 점수를 유지합니다.
6. **입력 오류 처리:** 잘못된 메뉴 번호, 빈 입력, 숫자 변환 오류, 파일 누락·손상 등을 처리합니다.

## 4. 기술 스택
- Python 3
- JSON (`state.json` 데이터 저장)
- Git / GitHub (버전 관리 및 협업)

## 5. 파일 구조 (개발 목표 예시)
```text
codyssey-python-quiz/
├── README.md          # 프로젝트 소개 및 사용 안내
├── .gitignore         # Git 추적 제외 규칙
├── main.py            # 프로그램 실행 및 메뉴 진입점 (추후 개발)
├── quiz.py            # Quiz 클래스 (추후 개발)
├── quiz_game.py       # QuizGame 클래스 (추후 개발)
└── state.json         # 퀴즈 목록 및 최고 점수 (실행 중 생성/관리)
```

> 위 구조는 실습을 위한 **제안 예시**이며, 미션 PDF가 Python 소스 파일명을 지정한 것은 아닙니다. 이번 GitHub 문서화 실습에서는 `README.md`와 `.gitignore`만 작성합니다.

## 6. 실행 방법 (개발 완료 후)
1. Python 3을 설치합니다.
2. 프로젝트 폴더에서 터미널을 실행합니다.
3. 다음 명령어로 프로그램을 실행합니다.

```bash
python main.py
```

프로그램 실행 시 메뉴에서 퀴즈 풀기, 퀴즈 추가, 퀴즈 목록, 점수 확인, 종료를 선택합니다.

## 7. 데이터 파일 설명 (`state.json`)
프로젝트 루트의 `state.json`에 퀴즈 목록과 최고 점수를 UTF-8 형식으로 저장합니다.

```json
{
  "quizzes": [
    {
      "question": "Python에서 리스트를 나타내는 기호는?",
      "choices": ["()", "[]", "{}", "<>"],
      "answer": 2
    }
  ],
  "best_score": 0
}
```

- `quizzes`: 등록된 퀴즈 목록
- `question`: 문제
- `choices`: 4개의 선택지
- `answer`: 정답 번호 (1~4)
- `best_score`: 최고 점수

파일이 없거나 손상된 경우 기본 퀴즈 데이터로 복구하도록 구현합니다. 위 JSON은 **데이터 형식 예시**이며, 실제 완성본에는 5문항 이상을 포함해야 합니다.

## 8. GitHub 협업 기준
- `main` 브랜치에 공통 프로젝트 구조와 초기 문서를 먼저 구성합니다.
- 팀원들은 최신 `main`을 동기화한 후 필요한 기능에 대해 별도 브랜치를 생성할 수 있습니다.
- 기능 단위로 Commit하고, 필요 시 Pull Request 검토 후 `main`에 Merge합니다.
- 코드와 문서의 변경 사항을 함께 관리합니다.

- 실행 가능한 콘솔 퀴즈 게임과 GitHub 저장소 제출
